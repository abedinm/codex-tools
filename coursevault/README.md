# CourseVault

Responsive public resource-sharing web app for university students.

## Features
- Upload/share resources by department, semester, course code, teacher, and type
- Resource types: lecture note, previous question, slide, book link, YouTube link, lab report
- Search and filters
- Rating system
- Comments
- Download/view link support
- Report inappropriate or wrong resources
- Admin moderation mode to hide/delete reported resources
- Static hosting friendly for GitHub Pages

## Run

```bash
python -m http.server 5190
```

Open:

```text
http://127.0.0.1:5190/
```

Admin demo password:

```text
admin
```

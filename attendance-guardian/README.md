# Attendance Guardian

Mobile-friendly attendance tracker for university students.

## Features
- Login/signup
- Add courses with total, attended, missed, and required percentage
- Current attendance percentage
- Safe/Risky/Danger warning levels
- How many classes can be safely missed
- Weekly reminder permission button
- Course cards and chart

## Run

```bash
python -m http.server 5187
```

Open `http://127.0.0.1:5187/`.

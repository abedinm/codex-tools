# StudyBuddy Match

Minimal student-friendly web app for finding compatible study partners.

## Features
- Login/signup
- Student profiles with university, department, semester, courses, goals, time, style, and online/offline preference
- Profile privacy toggle
- Compatibility scoring
- Filters by course, semester, preference, and available time
- Contact request and simple chat log

## Run

```bash
python -m http.server 5188
```

Open `http://127.0.0.1:5188/`.

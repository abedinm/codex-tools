# LabReport Pro

Structured lab report editor for university students.

## Features
- Login/signup
- Autosave
- Templates for physics, chemistry, electrical, civil, and computer labs
- Sections: title, objective, theory, apparatus, procedure, data table, calculation, result, discussion, precautions, conclusion
- Editable data table with rows and columns
- Equation/calculation input
- Image upload and preview
- PDF export using browser print
- Clean responsive editor

## Run

```bash
python -m http.server 5189
```

Open:

```text
http://127.0.0.1:5189/
```
